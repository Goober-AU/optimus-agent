# Pre-registered experiment plan

Frozen before any live trial. Written 2026-10-27 on branch
`fix/occ3-statebridge-alignment-generalisation` at commit `01f16fd11`.
No result in this file may be changed after data collection starts.

## 0. What must be true for the campaign to succeed

A repair counts only if the receiver answers from the sender's state, with the
state dependence surviving a matched control that has the same sequence shape,
the same ordinary text and the same number of reserved positions.

Two independent numbers decide it, both computed from the same requests:

```
Delta_accuracy = accuracy(correct H) - accuracy(shuffled H)   over independent trials
Delta_margin   = margin(correct H)   - margin(shuffled H)     median over trials
```

`margin = log P(correct label) - max log P(other labels)` at the first
generation position.

## 1. Arms

Every arm uses an identical user turn, an identical question and an identical
number of reserved latent positions. Only the reserved row contents differ.

| arm | reserved rows | purpose |
|---|---|---|
| P | aligned prefix from the real sender state | positive (mathematically equal to `T`; see `PRODUCTION-SCALE-DEGENERACY.md` addendum) |
| S | same pipeline, hidden rows permuted before alignment | kills row correspondence |
| U | unrelated random rows, norm matched | kills content |
| N1 | zeros, same count | matched-shape null (state absent, shape present) |
| N0 | no attachment at all, plain request | no-attachment baseline |
| T | reference token embeddings of the same span, no hidden states | token-channel ceiling |
| F | full ordinary text of the same message | text upper bound |

`N1` and `N0` are different controls and must never be reported as one.

The `P` versus `T` arm is retained for completeness only. The offline audit
proves both arms produce the same prefix (relative difference 3e-05), so a
difference between them in the live trial would indicate a plumbing defect,
not a latent effect.

## 2. Layout arms (do this first, it is cheaper and independent)

Run the positive arm under each receiver layout before touching mathematics:

| id | layout |
|---|---|
| L0 | legacy prefix at absolute row 0 |
| L1 | legacy position, framing sentence present |
| L2 | marker layout, prefix inside the system turn |
| L3 | marker layout, prefix inside the user turn |
| L4 | marker layout plus an explicit instruction to use the continuous message |

Decision rule for this stage: if any `L*` arm lifts `margin(P)` above
`margin(T) + 0.5` in the correct-label sense while `margin(S)` stays flat, the
framing repair alone is sufficient and the mathematics work is unnecessary.
If all layouts leave `P` at `S` and `N1` level, proceed to stage 3.

## 3. Task sets

Stage A, category (single-token labels, 4 candidates: BIRD MAMMAL FISH
REPTILE). 16 animals, balanced 4 per label, each animal used once per arm.

Stage B, exact short strings: `hello` then 12 fresh 6-character
lowercase-alphanumeric nonces, generated by a committed seed and never shown
to the receiver in ordinary text.

Stage C, fresh unpredictable facts: 8 statements about invented entities.

## 4. Acceptance thresholds

Pre-registered, before seeing any answer:

- Stage A: `Delta_accuracy >= 0.25` (4 of 16 trials) AND `Delta_margin >= 0.5`
  nats, with the 95% bootstrap CI of `Delta_accuracy` excluding 0.
- Stage B: `Delta_accuracy >= 0.30` on nonces is NOT required. Exact nonce
  recovery is reported as-is and is not a gate.
- Any arm: a result is only counted if `P` also beats `T` by `Delta_accuracy
  >= 0.10`, otherwise the result is attributed to the token channel.
- A single `hello` success is not evidence and must not be reported as such.

## 5. Analysis

One script, committed before collection, that reads the raw request log and
emits: per-arm accuracy with Wilson intervals, per-arm margin distributions,
paired permutation test between `P` and each control, and the confusion matrix
for stage A. No metric may be added after seeing the data.

## 6. Leakage audit, per trial

Assert, mechanically, that the private answer string does not appear in: the
ordinary messages, the tool definitions, the system prompt, the control
payload, the receipt metadata, the error strings and the response text before
generation. Reuse `tests/test_semantic_leakage.py`.

## 7. Candidate matrix for stage 4 (mathematics)

Only entered if stage 2 fails.

| id | method | fitted on | depends on H by construction |
|---|---|---|---|
| A | current per-message whitened Procrustes | the transmitted rows | no (proved: `PRODUCTION-SCALE-DEGENERACY.md`) |
| B | frozen whitened Procrustes | independent calibration rows | yes |
| C | frozen affine orthogonal Procrustes | independent calibration rows | yes |
| D | frozen dual ridge | independent calibration rows | yes |
| E | frozen map plus explicit state residual: `Z = normcal(E_row) + beta * normcal(P_msg(H))` | calibration rows | yes, and `beta` is the experimental knob |
| F | token-reference only | nothing | no (control) |
| G | calibration-free state blend: `Z = normcal(E_row) + beta * normcal(H_msg)` | nothing (identity map) | yes, by `beta` |

Candidate G is a diagnostic, not a candidate production method. It uses the
identity map instead of any Procrustes, so a success proves only that the
receiver can read a norm-calibrated final-layer state placed beside the token
embeddings; it cannot be reported as StateBridge working. It needs no
calibration corpus, so it can run in the first window and it separates two
hypotheses that are otherwise confounded:

- if `beta > 0` arms stay readable and `Delta_margin` grows with `beta`, the
  receiver can read off-manifold state and a frozen map only has to improve the
  geometry;
- if readability collapses as soon as `beta > 0`, a map onto the embedding
  manifold is mandatory and calibration is not optional.

Candidate E exists because the per-message fit destroys state information by
construction; a frozen map alone may leave the prefix off the embedding
manifold, while `E` keeps the readable token channel and adds a bounded state
term. `beta` is swept in `{0, 0.05, 0.1, 0.2}` and is part of the method
identity.

## 8. Stop rules

- If stage 3 gives no separation after 16 trials, stop and report the narrower
  negative result rather than widening the search.
- If the receiver abstains in every arm, the blocker is decoding/framing, not
  mathematics; report that and do not change the solver.
- If `P` and `T` are indistinguishable, report that OCC-3 as shipped transmits
  the token channel, not the state channel.
- Never rerun a spent state handle. Every trial needs a fresh capture.

## 9. Cost

The full plan needs one supervised window for layout arms (L0-L4 x 3 arms) and
one for the mathematics arms. Each window must run under the existing
controller with automatic restoration.
