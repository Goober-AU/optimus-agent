- Fixed the edit tool silently corrupting non-UTF-8 files: edits on files that are not valid UTF-8 now fail with a clear error and leave the file byte-for-byte unchanged, matching the diff preview instead of writing back U+FFFD replacement characters.
- Fixed `mcp_call_<server>` tools coercing invalid arguments into confusing kernel-side tracebacks: a missing, non-string, or empty `tool` and a missing or non-object `arguments` now fail fast with a typed validation error before any kernel code runs.
- Fixed tail truncation mishandling CRLF output: the oversized-line rescue recognizes `\r` blank lines, kept blanks count their real byte cost, the byte budget is never overshot, and reported `outputBytes` always matches the returned content.
- Added end-to-end behavior tests for the edit tool (multi-edit happy path, missing and ambiguous old text, non-UTF-8 rejection, cancellation before access and between access and write, retry idempotence), `mcp_call_` argument validation and generated-code quoting, CRLF truncation accounting, and the Node worker protocol.
