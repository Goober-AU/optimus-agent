Added: OCC-2 codebook amortization for delivered agent-message bodies. The full dialect codebook legend is injected only when the listener's context does not already carry the same codebook identity (dialect id + version + leading sha256 prefix, the identity the OCC-2 wire header already carries); later bodies carry a one-line reference instead of the ~600-char legend, removing the O(messages x codebook) prompt growth that measured +32% total prompt tokens on SILO-BENCH while the wire itself shrank. Presence is derived by scanning the listener's live message list, never a volatile flag, so compaction, daemon restart and context rebuilds stay correct by construction (whatever the scan still finds is what the model still sees), and a re-tuned card re-injects automatically because its hash identity changes. Offline warm-profile cost analysis: -40% prompt tokens per message after the first injection (research/occ2opt/IMPL-CODEBOOK-AMORT.md).
