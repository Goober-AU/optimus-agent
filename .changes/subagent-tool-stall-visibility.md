- Added child tool-call duration visibility for RLM subagents: activity rows now carry a `sinceMs` start time, and roster/collect summaries recompute a live `activityElapsedMs` at read time so a silent long-running tool keeps showing a growing duration even when the child emits no events.
- Added stall state: when an executing tool call exceeds `DEFAULT_RLM_CHILD_TOOL_STALL_NOTICE_MS` (10 minutes), summaries additionally carry `stalledMs` while keeping the activity attached; the live duration is also exposed on `rlm.collect` result entries as `activityElapsedMs`/`stalledMs`.
- Added a one-per-stalled-call notice: roster and collect reads emit a single `RlmChildUpdate` to the parent chat with the wording `Child <name> tool <tool_name> has been running for <minutes> min`, tracked against the last-notified tool-call start and reset when the tool call ends; detection piggybacks on existing event/read traffic and spawns no timers, so an unobserved stall emits nothing.
- Kept the wire backward compatible: the new activity, snapshot, and collect fields are optional and absent from old serialized state.
