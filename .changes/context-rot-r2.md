- Fixed a mid-task turn stalling when automatic compaction was disabled at runtime while enabled in settings: the turn-end stop hook now consults the same predicate as the compaction executor, so a turn is only stopped for a compaction that will actually run.
- Fixed the session migration dropping a compaction boundary when the legacy first-kept index could not be resolved, which made every later compaction re-summarize already-summarized history; the migration now falls back to the first entry after the compaction.
- Fixed no-op compactions that stopped the turn and paid a full summary call to rewrite prose the previous compaction already persisted when nothing new could be summarized.
- Fixed compaction deadline-fallback boilerplate being fed back to the next summarizer as authoritative previous-summary prose.
- Fixed the read-files inventory in compaction summaries always being empty: tool calls that reference files through `path` or `paths` arguments now record reads structurally instead of through a stale tool-name allowlist.
- Fixed user-attached images being counted as zero tokens by the context estimator; every image site now shares one 1024-token cost convention.
- Changed the no-usage context estimate to include the system prompt and tool schemas so pressure readings no longer understate the request the provider receives, with the parts kept at zero on the usage-anchored path to avoid double counting.
- Added a structural handoff guard for extension-supplied compaction summaries, enforcing the same section shape the model path enforces so a hook returning an empty or inventory-only summary cannot silently delete the prefix it was supposed to summarize (the extension call site still needs to apply it).
- Added a provenance-aware typed-state module that classifies session material into fourteen information kinds, builds a merge-carried ledger with stable content-derived ids, allocates a priority budget with explicit overflow reporting, and deterministically verifies compacted output; it is the replacement path for the keyword-regex task-state ledger and is not yet wired into the compaction flow.
- Added a `compaction-harness` binary that runs the real compaction pipeline (session append, compaction with a fixture summarizer, restore bookkeeping) over one JSON request on stdin, for offline benchmark adapters.
- Added the context-rot iteration-2 research harness: a production-path multicycle benchmark adapter with scenario and scoring drivers, a CompactBench adapter that runs the real pipeline inside the official runner, an offline ContextBench evaluation pipeline with repo-level dev/holdout split and matched A/B harness, an incremental-variant experiment driver, and the campaign reports under `reports/context-rot-r2/`.
