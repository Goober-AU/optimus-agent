- Fixed a mid-task turn stalling when automatic compaction was disabled at runtime while enabled in settings: the turn-end stop hook now consults the same predicate as the compaction executor, so a turn is only stopped for a compaction that will actually run.
- Fixed the session migration dropping a compaction boundary when the legacy first-kept index could not be resolved, which made every later compaction re-summarize already-summarized history; the migration now falls back to the first entry after the compaction.
- Fixed no-op compactions that stopped the turn and paid a full summary call to rewrite prose the previous compaction already persisted when nothing new could be summarized.
- Fixed compaction deadline-fallback boilerplate being fed back to the next summarizer as authoritative previous-summary prose.
- Fixed branch summaries being built from a conversation with every tool result removed: tool output now reaches the branch summarizer paired with its assistant call under the same evidence-aware excerpt policy as the main compaction path, and the budget walk keeps the call of a kept result so the retained window never starts at an orphaned result.
- Fixed superseded harness digests accumulating in the provider context: only the newest digest was compared, so k harness changes left k digest user turns (k-1 stale) in the request; an incoming digest now supersedes every older one in the live context while the durable transcript keeps the full history.
- Fixed memory-recall text reaching the provider as unfenced, instruction-shaped user turns that stored project data could read as fresh user direction: recall text is now wrapped in a `<memory_data>` fence at provider-context conversion, mirroring the harness-digest fence.
- Fixed fail-closed memory recall failing silently: a corpus scoped entirely to a foreign project or host, the render-space short skip and the stale-source skip now surface one rate-limited warning with drop counts when hits existed but nothing rendered.
- Fixed the read-files inventory in compaction summaries always being empty: tool calls that reference files through `path` or `paths` arguments now record reads structurally instead of through a stale tool-name allowlist.
- Fixed user-attached images being counted as zero tokens by the context estimator; every image site now shares one 1024-token cost convention.
- Fixed the task-state ledger renumbering item ids on every merge, which let a retired id be re-issued to newly captured content and silently deleted, and user corrections superseding each other while the decisions they corrected stayed current: ids are now derived from item content so a retired id only ever suppresses the exact content it was assigned to, and a correction retires the best-matching older decision or constraint, with the newest correction winning when two target the same item.
- Changed the no-usage context estimate to include the system prompt and tool schemas so pressure readings no longer understate the request the provider receives, with the parts kept at zero on the usage-anchored path to avoid double counting.
- Added a structural handoff guard for extension-supplied compaction summaries, applied at the extension compaction call site and enforcing the same section shape the model path enforces, so a hook returning an empty or inventory-only summary cannot silently delete the prefix it was supposed to summarize.
- Added a `typed` mode to the `taskState` compaction setting alongside `off` and `prompt` (default unchanged): the provenance-aware typed-state ledger classifies session material into fourteen information kinds, merges with the ledger persisted by the previous compaction, renders a protected block sized from the summary budget, and verifies the compacted output, appending missing protected lines back deterministically without a model call and failing the compaction up front when mandatory material cannot fit the budget.
- Added a calibration harness for the context-health score: a labelled synthetic corpus and a pure metric layer (rank-based ROC-AUC, Brier, calibration error, threshold rates) that quantify how well the score predicts semantic constraint loss; measurement only, nothing in production reads these metrics.
- Added end-to-end regression coverage that subagent task constraints survive parent compaction: a child task handed out after the parent compacted, a parent task crossing the compaction boundary mid-child, and a child report resolving in the parent's compacted context.
- Added a `compaction-harness` binary that runs the real compaction pipeline (session append, compaction with a fixture or env-configured live-provider summarizer, restore bookkeeping) over one JSON request on stdin, for offline benchmark adapters.
- Added the context-rot iteration-2 research harness: a production-path multicycle benchmark adapter with scenario and scoring drivers, a CompactBench adapter that runs the real pipeline inside the official runner, an offline ContextBench evaluation pipeline with repo-level dev/holdout split and matched A/B harness, an incremental-variant experiment driver, live-model experiment drivers for multicycle recall, coding-task action probes with a simulated process restart and an adversarial correction suite, an offline replay that re-measures the ledger fix against a committed live corpus, live-model practice runs of both external benchmarks through the harness binary, and the campaign reports under `reports/context-rot-r2/`.
