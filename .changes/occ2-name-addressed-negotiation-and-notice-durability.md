- Fixed name-addressed agent messages never negotiating OCC-2: the send-seam peer lookup only matched session ids, so a send that succeeded by session name silently stayed OCC-1 even with a capable, opted-in peer. The policy now resolves peers by `active_session_id`, `session_id` or `session_name` (the same selectors the roster accepts), and a duplicate `on_session_published` for a daemon-hosted child is a no-op instead of double-arming the run's abort.
- Fixed terminal RLM child notices (completion and deletion) being dropped after one failed persistence attempt: the notice publish is retried up to three attempts with linear backoff, and the last error is surfaced to the caller when every attempt fails.
