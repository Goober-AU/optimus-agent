- Fixed refinement failures disappearing silently while a local model gateway is down: a failed refinement now writes a `status: failed` record to the harness refinement history and a persisted transcript notice, so lost lessons are audible and auditable instead of vanishing with the terminal. Attached CLI output already printed the error; daemon/RLM sessions previously kept no durable trace.
- Added opt-in recovery for loopback model providers: when a provider call fails because the local gateway is down, the agent can run a configured start command, wait a bounded time for the port to accept connections, and retry the model call exactly once. Cancelled requests are never retried, and non-connection failures keep the single-attempt contract.
- Added the typed `localGateway` settings object for the recovery (`autoStart` default false, `startCommand`, `probeTimeoutMs` default 1500, `startTimeoutMs` default 20000); a missing object keeps current behavior, and an existing object round-trips verbatim with unknown keys preserved.
