- Added a bounded single retry for the recall rerank helper: when the rerank LLM call returns no usable selection (no output, unparseable output, or an empty selection), the same call is retried exactly once before the lexical fallback stands. Cancelled requests are never retried, and helper usage is summed across both calls. The retry is observable via a new `retried` field in the rerank helper report, so diagnostics distinguish first-call successes from retry recoveries.
