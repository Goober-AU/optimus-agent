- Changed worker-to-supervisor agent messaging to reuse one authenticated daemon connection per supervisor socket instead of connecting, handshaking, and tearing down a fresh pipe or Unix socket per message: mean send latency drops from 1.153 ms to 0.553 ms (2.08x) and 200 sequential sends now cost 1 accept instead of 200. Measured under throttled gate (4 CPUs shared, -j 2, BelowNormal); Windows named pipes, 200 sends per arm, debug test binary.
- Preserved at-most-once delivery: a command is sent at most once, failures after the write are returned and never replayed, dead cached connections reconnect once before falling back to the historical retry loop, and idle connections release their pipe after 60 s.
